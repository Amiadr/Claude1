ייבוא הקלטה קיימת

הקלטת לילה שלם באפליקציית רשמקול? בחר את הקובץ. האפליקציה תקרא ממנו את שעת ההתחלה, תסרוק אותו כאן במכשיר (שום דבר לא מועלה) ותשמור רק את הקטעים עם רעש, עם השעה המדויקת של כל אחד.

הצ'יפים הם הצעות מהקובץ. אם המרת את הקובץ לפורמט אחר, הזמן שבו לא נכון: הזן כאן את הזמן מההקלטה המקורית, או שמור את השם המקורי של הקובץ ואז הוא נקרא ממנו.

      איך להשתמש ומה חשוב לדעת
      • הנח את המכשיר קרוב לקיר או לרצפה שמהם מגיע הרעש, מחובר למטען. השאר את הדף פתוח ולחץ "מסך לילה".
      • באנדרואיד: כבה "אופטימיזציית סוללה" לדפדפן (Chrome) בהגדרות האפליקציה, אחרת המערכת עלולה לעצור את ההקלטה.
      • באייפון: ההקלטה נעצרת כשהמסך ננעל. השאר את המסך דלוק (ההגדרה "השאר מסך דלוק" מטפלת בזה ב-Safari 16.4 ומעלה).
      • הכי אמין: מחשב נייד עם Chrome, מחובר לחשמל, עם כיבוי שינה אוטומטית.
      • הכל נשמר במכשיר בלבד. ייצא ZIP בבוקר ושמור עותק בענן או במחשב. מחיקת נתוני האתר בדפדפן מוחקת גם את ההקלטות.
